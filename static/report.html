Capacités actuelles

  1. Mail Manager est une interface web pour charger et trier des emails Gmail.
  2. Le backend FastAPI expose une API JSON et sert l'UI statique.
  3. Connexion Gmail via OAuth (credentials.json + token.json).
  4. Lecture des messages en mode read-only.
  5. Recherche Gmail paramétrable via une requête.
  6. Limitation configurable du nombre d'emails chargés.
  7. Extraction des métadonnées: expéditeur, sujet, date, extrait.
  8. Analyse IA via un provider compatible OpenAI.
  9. Prompt système orienté filtrage et priorisation.
  10. Retour IA attendu: keep_ids, ordered_ids, summary.
  11. Fallback si réponse IA non conforme (sanitization).
  12. CORS configurable via ALLOWED_ORIGINS.
  13. Page d'accueil HTML/JS pour charger les emails.
  14. Formulaire pour saisir des instructions IA.
  15. Affichage des emails chargés dans l'UI.
  16. Affichage de la synthèse IA et de l'ordre recommandé.
  17. Gestion des erreurs côté API avec messages clairs.
  18. Configuration IA par variables d'environnement.
  19. Support d'un base_url IA optionnel.
  20. Exécution locale via uvicorn.
  21. Support Docker avec secrets séparés.
  22. Compatibilité Fly.io décrite.
  23. Aucune suite de tests fournie.
  24. Projet conçu pour un usage simple et direct.
  25. Ce compte rendu reflète l'état actuel du dépôt.
